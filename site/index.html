The workbench

Everything you expect from your editor. Already there.

Explorer, search, editor, Git, terminal and background tasks are part of oneClient itself — shared by every plugin, with the shortcuts you already know.

Source Control, like VS Code

Stage, unstage and discard changes; commit, amend, push or sync from one box; read diffs side by side or inline; check out and create branches. A commit graph shows branch lanes and refs.

It runs your own git, so hooks, credentials and config just work.

Background tasks

oneClient finds your package.json scripts, .vscode/tasks.json and .oneclient/tasks.json tasks, and .NET builds. Run them in the background with live output, progress in the status bar, Stop and Run Again.

Git fetch, pull and push, and long plugin jobs, are tracked here too.

Search every folder at once

Match case, whole word and regular expressions, include and exclude globs, and replace per file or everywhere. Results are grouped by file; click one to jump to it.

Search runs on a background worker, so the window stays responsive on large repos.

  • Integrated terminalPowerShell, Command Prompt, Git Bash, WSL, bash and zsh, in the bottom panel.
  • Command paletteEvery core and plugin command, filtered as you type (Ctrl+Shift+P).
  • A real editorFind / replace, go to line, formatting, breadcrumbs and syntax highlighting.
  • Menus & shortcutsFile, Edit, View, Go, Run, Terminal and Help — keyboard-first, like VS Code.
  • Themes & iconsColor themes and file-icon themes, switchable live.
  • Portable configPlain JSON in ~/.oneclient; passwords encrypted with your OS keychain. Export and import connections.

Plugins

Purpose-built tools for each piece of your stack.

Not a generic tree with a text box — each plugin brings the views that tool deserves.

PostgreSQL & SQL Server

Browse databases, schemas, tables, views, functions, procedures and sequences — with columns, keys and indexes. Query windows have IntelliSense, multiple result sets and server messages.

Apache Kafka

Brokers, topics and consumer groups. Browse and filter messages by partition and offset, inspect headers and JSON values, view partitions and configuration, and produce new messages.

HTTP client

Collections, folders, environments and history. Params, headers, body, auth and variables — and import straight from Postman or cURL.

Redis

A key tree grouped by namespace, editors for strings, hashes, lists, sets, sorted sets, streams and JSON, plus TTL, rename and delete.

Built to be extended

Your tool isn't here yet? Write the plugin.

The core has no tool-specific code at all. Plugins declare connection types, explorer trees, editor views, commands and menus in a manifest, and each one runs in its own process — so a crashing plugin never takes down the app.

  • One typed package to depend on: @oneclient/plugin-api
  • Views in any web framework, hosted in their own sandboxed view
  • Shared workspace, tasks, search and editor APIs
  • Enable or disable plugins live — no restart
Read the plugin API →
oneclient.json
{
  "name": "oneclient-postgres",
  "displayName": "PostgreSQL",
  "engines": { "oneclient": "^0.1.0" },
  "main": "dist/main.js",
  "contributes": {
    "connectionTypes": [{
      "id": "postgres",
      "label": "PostgreSQL",
      "category": "Databases",
      "connectionLabel": "Server"
    }],
    "explorerNodes": [ … ],
    "views": [ … ],
    "commands": [ … ]
  }
}
