# oneclient-mssql — SQL Server client for oneClient

A **Microsoft SQL Server / Azure SQL client** for [oneClient](../../../README.md) — a small SSMS inside a VS Code-style window.

- **Object explorer:** databases, tables, views, procedures, functions, columns, keys and indexes.
- **Query windows** with IntelliSense, multiple result sets and server messages; results you can sort, filter and export.
- **Shared SQL tools** from `@oneclient/sql-core`: query history, background queries, table data editor with staged changes, CSV import, execution plans, Create Database, SSH tunnels and ER diagrams.
- **Fast Tools:** saved queries per database and a **fake-data generator**.
- **AI tools:** the AI Assistant plugin can read the schema and run read-only queries on a connection (statements that change data wait for your approval).
- **Docker template:** SQL Server 2022 Developer edition in one click, with a ready connection.
