# oneclient-azure-blob — Azure Blob Storage explorer for oneClient

An **Azure Blob Storage explorer** (and **Azurite** client) for [oneClient](../../../README.md), the VS Code-style client for SQL, Kafka, Redis, APIs and Docker.

- **Containers and folders**, upload and download.
- **View and edit text blobs**, properties, metadata and access tiers.
- **SAS links** for sharing a blob.
- **Docker template:** Microsoft's local Azure Storage emulator (Azurite, blob service) with a ready connection.
