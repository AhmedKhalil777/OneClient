# oneclient-redis — Redis GUI for oneClient

A **Redis browser and editor** for [oneClient](../../../README.md), the VS Code-style client for SQL, Kafka, Redis, APIs and Docker. Works with Redis, Valkey and compatible servers.

- **Key browser:** keys grouped into a namespace tree, with search.
- **Editors for every data type:** strings and JSON, hashes, lists, sets, sorted sets and streams.
- **TTL, rename and delete**, server info, slow log and a built-in CLI.
- **Docker template:** start a password-protected Redis 7 container from the Docker plugin and get a ready connection.

Looking for a free Redis GUI that lives next to your database client, Kafka UI and HTTP client? Install oneClient and add a *Redis* connection.
