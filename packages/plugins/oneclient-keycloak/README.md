# oneclient-keycloak — Keycloak admin for oneClient

A **Keycloak admin console for developers** inside [oneClient](../../../README.md), the VS Code-style client for SQL, Kafka, Redis, APIs and Docker. It talks to Keycloak's admin REST API.

- **Realms, users, groups, roles, clients, client scopes, identity providers, sessions and events.**
- **JSON editing** of any resource, and role mapping.
- **Developer token tools:** decode a JWT, get a token, introspect it, and evaluate what a user gets.
- **Docker template:** Keycloak in `start-dev` mode with an admin user, ready to connect.
